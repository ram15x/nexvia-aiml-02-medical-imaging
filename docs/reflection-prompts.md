# Individual reflection prompts

Use these prompts to shape a reflection in your own words:

- Which parts of the platform did I build or contribute to?
- What did I learn about patient-level splits and report-mined labels?
- Which model or engineering decision was guided by measured evidence?
- How did I connect the model code to the API and browser workflow?
- What result or implementation detail changed how I approached the project?
- What would I improve next with more data, time, and domain review?
- Which project artifacts best show my contribution?
